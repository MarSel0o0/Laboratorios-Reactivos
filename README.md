# Laboratorios-Reactivos

Repositorio para almacenar las implementaciones del equipo para una serie de laboratorios de TypeScript y React.

Los laboratorios se nombrarán de la siguiente forma:

- laboratorio 1
- laboratorio 2
- laboratorio 3
- ...

## Convención de las ramas

Cada uno, para cada laboratorio, deberá crear una rama con la siguiente sintaxis

{nombre}/lab{n° del laboratorio}

>> Por ejemplo, para el laboratorio 1, mi rama es `marselo/lab1`
